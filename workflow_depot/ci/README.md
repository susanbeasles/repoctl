# Integration quality adapter

Call `.github/workflows/integration-quality.yml` from the application CI for `push` on `int/**`. Supply the reviewed depot full SHA, qualified runtime image with an immutable sha256 digest, and the real build output directory. No application callers are activated by this source change. The outer application caller must delegate contents read, security-events write and id-token write for the reusable security workflow’s declared jobs; admission-mode scanner jobs themselves retain contents read only and skip all CodeQL/OIDC jobs. The runtime must contain Node and any project-specific quality tools; missing tooling fails.

Source admission runs first without candidate execution. Only its explicit PASS permits the isolated quality job. Node projects retain their existing `npm run test` runner and must declare lint, typecheck, test and build scripts plus a lockfile. Configure lint with the project's reviewed ESLint policy and typecheck appropriately; no implicit framework replacement occurs. Python projects provide explicit argv arrays in `.workflow-depot-quality.json`: pythonInstall, pythonLint, pythonTypes, pythonTests, pythonBuild. Use Ruff, the project's type checker, and its compatible existing unittest/pytest runner; dependency installation should be locked with hashes. Mixed projects run both profiles. Every required command must succeed.

The single quality job builds once, captures the real output inventory and binds SHA256 digests to source SHA, integration ref, repository, run ID and attempt. Links and special files are rejected. Private repositories are required for captured sourcemaps; the workflow has no release publishing or public upload. Project child processes receive only basic runtime environment, not inherited secrets or OIDC variables.

Full original security policy runs after quality succeeds. The new `admission_only` adapter input defaults false; admission PASS alone never grants release/promotion authority. Mandatory CodeQL behavior and licensing failures remain unchanged. Every original module file is hash checked against the import manifest.

The remaining source wiring is in [PIPELINE-WIRING.md](PIPELINE-WIRING.md): private-preview guards, owned CodeQL configuration, explicitly approved pinned reviewer, accepted-main artifact consumption, retained promotion envelopes, central dispatch and official CLI-only Environment custody. These capabilities fail closed on missing evidence/configuration and do not commission producers, targets or deployment authority. The Worker artifact contract is preserved; signer Container support remains separately blocked.

Offline checks: `node --test test/*.test.mjs`, `python ci/check-orchestration.py`, `python scripts/check-security-assurance-import.py`. These do not run scanners or project tooling.
